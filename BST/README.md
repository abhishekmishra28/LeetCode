# Binary Search Tree (BST) Problems

This folder contains problems based on **Binary Search Trees (BST)**.
BSTs are a special type of binary tree that maintain an ordered structure,
making search, insertion, and deletion efficient.

---

## 🎯 What you’ll practice here

- Understanding BST properties and invariants  
- Searching, inserting, and deleting nodes  
- Using BST order to optimize solutions  
- Solving range-based and order-based queries  
- Writing recursive and iterative BST solutions  

---

## 🧩 Core BST properties

For every node in a BST:
- All values in the **left subtree** are **less than** the node’s value  
- All values in the **right subtree** are **greater than** the node’s value  

This property enables efficient operations.
